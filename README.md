# Портфолио «Лидер года» — Александра Барабан

Интерактивный анимированный веб-лендинг конкурсного портфолио для конкурса **«Лидер года»**.

**Героиня:** Барабан Александра Витальевна  
**ВУЗ:** УО «Гродненский государственный университет имени Янки Купалы», Факультет экономики и управления  
**Специальность:** Электронная экономика, 3 курс

---


## 🎨 Дизайн

- **Палитра:** NYNÄ @nynatrema (Soft Blush, Old Rose, Pale Slate, Cool Steel, Taupe Grey)
- **Шрифты:** Cormorant Garamond (заголовки), Plus Jakarta Sans (основной текст)
- **Стиль:** Sapphire & Gold Neo-Editorial → переработан в розово-стальную палитру

### Особенности лендинга:
- SVG-радар компетенций с 5 гранями лидерства (99% интеллект, 98% ораторство, 97% культура, 98% лидерство, 96% гражданственность)
- Фильтры дипломов по 5 категориям
- Bento-сетка проектов
- Lightbox для просмотра дипломов и фото
- Видеоплееры с выступлениями
- Scroll-reveal анимации (IntersectionObserver)
- Анимированный фон с частицами

## 🚀 Деплой

### Vercel (рекомендуется)
1. Запушить репозиторий на GitHub
2. Подключить на [vercel.com](https://vercel.com) → Framework Preset: **Other**
3. Сайт онлайн за ~30 секунд

### GitHub Pages
1. Settings → Pages → Source: `main` branch, root folder
2. Доступно по адресу `https://<username>.github.io/<repo>/`

### Cloudflare Pages
1. Подключить GitHub-репозиторий
2. Build command оставить пустым (чистый HTML)
3. Publish directory: `/`

## 🛠️ Генерация DOCX-буклета

```bash
pip install python-docx Pillow
python build_booklet_docx.py
```

Скрипт генерирует двусторонний печатный буклет формата А4 с:
- Титульной страницей (фото + биография + матрица 4 векторов достижений)
- Хронологическим реестром всех 14+ дипломов и инициатив
- Миниатюрами ключевых дипломов
- QR-кодами на Telegram и YouTube
